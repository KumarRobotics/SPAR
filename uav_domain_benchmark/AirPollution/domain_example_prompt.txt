Example 2. Monitoring at one region
Action: This action allows a uav to monitor in the current region if the required monitoring time of that region has not yet been reached. Each execution of this action increases the region's monitoring time by one unit. For example, if the uav is in region_1 and the required monitoring time for region_1 is 3 units, then executing this action will increase region_1's monitoring time by 1 unit.
